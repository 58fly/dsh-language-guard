# 缺陷：插件显示名「中文语言守卫」与通用语言锁定器定位不符（0.1.2 已改名为「语言守卫」）

## Answer

### 一、问题成立，且比表面更严重

插件本身是**通用语言锁定器**：目标语言可配（`zh-CN` / `zh-TW` / `en` / `ja` / `ko` 预设，加任意合法 BCP-47），默认简体中文。但显示名把语言锁死在中文上。

| 位置 | 0.1.1 的值 | 问题 |
|---|---|---|
| `locale/zh.json` `meta.title` | 中文语言守卫 | 锁死中文 |
| `locale/en.json` `meta.title` | Language Guard | 正确 |
| `client.js` zh `card.title` | 中文语言守卫 | 锁死中文 |
| `client.js` en `card.title` | Chinese Language Guard | **与 `locale/en.json` 不一致** |
| `icon.svg` `aria-label` | 中文语言守卫 | 锁死中文 |
| `README.zh.md` / `README.md` 首行 | 中文语言守卫 / Chinese Language Guard | 锁死中文 |
| `package.json` `description` | Enforce Simplified Chinese… | 锁死中文 |

即：不只是名字不对，**中英两版本身也不一致**。

### 二、定案名称

用户选择：**语言守卫 / Language Guard**。与包名 `dsh-language-guard` 一一对译，不绑定任何具体语言。

### 三、修复（0.1.2）

同步 9 处：`locale/zh.json`、`locale/en.json`（title + description）、`client.js` 的 zh/en 字典各 2 键、`icon.svg` 的 `aria-label`、`README.zh.md`、`README.md`、`package.json` 的 `description`。

`meta.description` 一并改为「把模型的思考过程与回复语言锁定为**指定语言**（默认简体中文）」。

**未改**（避免破坏已装用户）：包名 `dsh-language-guard`、section 名 `language-guard:head/mid/tail`、`/language` 命令、config 字段名、NS `languageGuard`。
